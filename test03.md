Title: Behavior when the hour field is set to "13" 
Do this: Set the hour field to "13", set the minute field to "00", set the period to "AM", then press the "Save/Activate" button. 
Expect: Either the field rejects the value or the configuration of the alarm fails.

Question for product owner: What happens when the hour field receives
a value outside the valid 1–12 range — is it blocked at input, or does
it fail on save?

Title: Setting an alarm succeeds with the period set to PM
Do this: Set the hour field to "07", set the minute field to "00", set the period to "PM", then press the "Save/Activate" button.
Expect: The alarm shows as active (e.g. a toggle or list entry for 07:00 PM). The alarm rings at 7:00 PM (19:00), not 7:00 AM.
